# Explorer Quest

Ava's Unit 3 Exploration study app (test 10/27). Four round types:

- **Full review** (20 Qs) — a mix of everything below
- **Lesson 1 — Vocabulary** (22 Qs): 11 words (merchant, navigation,
  enslaved, missionary, ally, astrolabe, orienteering compass, sextant,
  Silk Road, caravel, conquistador), each asked both as multiple choice and
  typed recall with typo tolerance
- **Lesson 2 — Spain & Portugal** (9 Qs): Dias, da Gama, Columbus→Taino,
  Cortés→Aztec, Pizarro→Inca, the effects of each encounter, and where the
  Spanish traveled
- **Lesson 3 — France, England & the Dutch** (10 Qs): New France /
  St. Lawrence / fur, New England / Atlantic / fishing, New Netherland /
  Hudson — plus **map questions** on a drawn schematic of the Americas,
  because the map is on the real test

The study screen includes the labeled map and the full word list with
memory hooks. Scores sync across devices via Cloudflare Workers KV
(`functions/api/scores.js`, binding `SCORES`).

Live: https://explorer-quest.pages.dev
